# Nubra Python SDK service

This service runs the official Nubra Python SDK outside Vercel and exposes a small authenticated HTTP interface for the web application.

## Authentication

This service uses Nubra's documented server-side TOTP login flow. First enable TOTP once on the Nubra account using the SDK setup flow. Then configure these private Render environment variables:

- `NUBRA_PHONE_NO`: registered 10-digit phone number
- `NUBRA_MPIN`: Nubra MPIN
- `NUBRA_TOTP_SECRET`: TOTP secret generated by Nubra
- `SERVICE_API_KEY`: generated by Render

Never commit these values to GitHub or send them in chat. The service reuses one authenticated SDK client and refreshes it before the documented session expiry window.

## Deploy

Use Render Blueprint deployment with this folder's `render.yaml`. Set the three Nubra variables in the Render dashboard. Copy the generated `SERVICE_API_KEY` and the deployed service URL into Vercel as `NUBRA_PYTHON_API_KEY` and `NUBRA_PYTHON_API_URL`.

The Render service is separate from the Vercel frontend because Vercel's Node.js runtime does not execute the Python SDK.

## API

- `GET /health`
- `POST /v1/historical` with header `x-service-key`, at most five instruments per request.

The service only fetches market data. It does not place orders.
